# Teleprompter Project — Agent Guide

## Active files (served by the Python server)

- **`static/index.html`** — HTML template (this is what the browser loads at `/`)
- **`static/app.js`** — Client-side JavaScript (loaded by `index.html`)
- **`static/style.css`** — Stylesheet
- **`server.py`** — Python HTTP + WebSocket server (serves `static/`)

## Orphaned / not served

- **`teleprompter.html`** — standalone single-file version, NOT served by `server.py`. Do not edit this file unless explicitly told to.
- **`teleprompter.json`** — server config persistence, auto-managed.

## Always edit both `static/` files when making UI/JS changes.

Changes to `static/index.html` or `static/app.js` require a server restart (`Ctrl+C` then re-run `python3 server.py` or `run.sh`).
